## Career Transition: Frontend → Machine Learning

**Why this transition:**

Programming has always been more than just a job for me — it's a hobby. I've always enjoyed using code to solve everyday problems.

After about 5 years of web development, I became fascinated with microcontrollers. They opened up a whole new dimension — the physical world. Suddenly I could collect data from sensors and control real mechanisms. It was incredibly rewarding to see my code affect something beyond a screen.

Soon I ran into challenges that were beyond my skills — like recognizing digits on a meter. That's when I first became interested in computer vision and OpenCV. My first attempt used nearest neighbors, and the results weren't great, but it was a start.

Later, I worked on projects where I needed to process ADC signals from microcontrollers. Using math to smooth out signal peaks was a breakthrough moment — I realized that mathematics shouldn't just be studied at university, it should be used in practice.

Now I'm entering the next stage of my growth. After years of moving data from backend to frontend and presenting it beautifully, I'm now fascinated by what data actually represents — exploring it, finding patterns, and discovering value hidden inside. And the visual aspect I used to focus on in web interfaces has naturally evolved into an interest in computer vision.

**Currently focused on:**
- Python for Data Science (NumPy, Pandas, Matplotlib)
- Machine Learning fundamentals (scikit-learn)
- Deep Learning & Computer Vision (OpenCV, neural networks — in progress)
